# FE Bar 2026 Submissions Repo

This repository is reserved for my 2026 FE Bar submission, a build of the Volta Industrial example we used for our AI Customer Challenge at Tech Summit. I have modified it to include:

* The ML Scoring notebook and pipleine adjustements
* Visual/UI Updates
* Updated Genie Agent

The structure of the repo has all of the deployed assets. The evidence folder has the saved:

* Notebook training and scoring output
* Pipeline output JSONs to show it ran and loaded all of the required data and assets
* Gene Agent conversation logs
* Lakebase git diffs to show I used Lakebase branching in my work
